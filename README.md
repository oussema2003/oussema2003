# Hi, I'm Oussema Hidouri

I'm an AI and machine learning developer from Tunisia. I enjoy turning research ideas into software that actually works, whether that means training a model from scratch or getting one to run reliably behind an API.

---

## About me

I mostly work on deep learning, with a focus on computer vision and natural language processing. I like the full path from a messy dataset to a deployed model, and I care as much about the pipeline around a model as about the model itself.

Lately I've been spending my time on:

- Computer vision: image classification, object detection and segmentation
- NLP: text classification, sentiment analysis and working with language models
- Building and training neural networks from scratch to understand how they behave
- Packaging models into small, usable applications with FastAPI and Streamlit
- Exploratory data analysis and visualization before any modeling begins

- Generative models: GANs, VAEs and diffusion models
